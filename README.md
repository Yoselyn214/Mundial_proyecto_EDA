
# Grafo y Estructuras de Datos del Mundial

Visualizador interactivo de estructuras de datos aplicadas al mundial. Este proyecto está desarrollado con **React**, **TypeScript** y **Vite**, y servirá como base para la implementación de estructuras de datos avanzadas como **Heavy-Light Decomposition (HLD)** y **estructuras persistentes**.

## Requisitos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- Node.js
- npm

Puedes verificar la instalación con:

```bash
node -v
npm -v
```

## Instalación

Instala las dependencias del proyecto:

```bash
npm install
```

## Ejecución

Inicia el servidor de desarrollo con:

```bash
npm run dev
```

Una vez iniciado, abre tu navegador y accede a:

```
http://localhost:3000
```
